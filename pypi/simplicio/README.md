# Simplicio — AI Coding Agent

Save up to 96% on AI tokens. Single binary, runs on your machine.

## Install

```bash
python3 -m pip install --upgrade simplicio-installer
simplicio install
```

Then use:

```bash
simplicio chat "build a login endpoint and test until it passes"
```
